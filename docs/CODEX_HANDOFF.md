- 필터 적용값이 실제로 달라질 때만 기존 목록을 220ms 페이드아웃한다. 사라진 뒤 필터 결과를 교체하고 가로 위치를 처음으로 되돌린 다음 320ms 페이드인한다. 전환 중 휠/클릭 입력을 막고, 모션 감소 설정에서는 즉시 교체한다.
- 필터 모달의 적용/취소 및 버튼 호버 규칙은 유지한다. 페이드 시간은 체감 확인 후 조정 가능한 구현값이다.

Archive 테스트 페이지 최신 조정
- `/archive-prototype` 작품열의 스크롤바를 숨기되 가로 스크롤 자체는 유지한다.
- 페이지 전체 휠·트랙패드 입력에 Index와 같은 속도 기반 관성을 적용한다. 입력 종료 후 지수 감속하고 역방향 입력은 방향을 바꾼다. 터치 시작/필터 열기/화면 이탈 때 관성을 멈춘다. 모션 감소에서는 추가 관성 없이 입력량만 이동한다.
- 작품 이미지에 호버하거나 키보드 포커스가 가면 8px 위로 올라간다. 이미지 클릭은 `/archive-prototype/:artworkId`의 1차 상세 화면으로 연결한다. 상세 화면은 작품 이미지와 기존 메타데이터 및 Archive 복귀 링크만 임시로 담는다.
- 필터 버튼은 호버 시 크기 변화 없이 청록색만 진해진다. 기존 필터 기능·모달 연출은 유지한다.

Archive 1차 테스트 화면 (확정 요구와 임시 구현 구분)
- 리뉴얼 Archive는 `/archive-prototype`에서 검토한다. 현재 `/works` 화면은 유지하며 GNB의 일반 Archive 링크도 당분간 `/works`로 연결한다. 테스트 주소로 직접 접근할 수 있다.
- 작품 목록은 화면 하단 가로 방향으로 놓고 원본 비율을 유지한 고정 높이 이미지와 제목·크기/재료/연도 메타데이터를 표시한다. 페이지 어느 곳의 휠/트랙패드 및 목록 터치 스와이프로 좌우 탐색한다. Index의 마우스 XY/Z 흔들림은 적용하지 않는다.
- ARCHIVE 제목 옆 필터 버튼은 호버 동작과 필터 모달 등장/퇴장 모션을 갖는다. 기본 상태는 전체 선택이다. 적용 후 전체 선택이 아니면 선택된 항목 수를 버튼 배지로 표시한다.

- 모달의 전체 선택·전체 취소·개별 선택·취소·적용을 지원한다. 취소 시 선택 변경을 버리고 적용 시 작품 목록을 갱신한다. 배경 클릭과 Escape로 닫는다.

최신 데스크톱 관성 변경
- 휠·트랙패드 입력의 크기와 반복에 따라 이동 속도를 누적하고, 입력 종료 후에도 서서히 감속하며 이동한다. 반대 방향 입력은 기존 방향의 관성을 즉시 버린다.
- 구현 조정값: 속도 최대 4px/ms, 감쇠 시간상수 320ms, 입력 속도 가산 delta × scrollSensitivity / 160. 모션 감소 설정에서는 추가 관성을 사용하지 않는다.
- 목록 경계에서 멈추고 키보드·터치 입력 및 창 포커스 해제 시 관성을 중단한다. 트랙패드 핀치 줌(ctrl+wheel)은 가로 탐색으로 처리하지 않는다. 실제 휠/트랙패드 감도는 후속 체감 확인 대상이다.

1. 문서의 적용 범위와 우선순위
이 문서는 기존 Index 기획 중 작품 나열·스크롤 이동·작품 정보 표시 규칙을 대체한다. 기존 docs/readme.md에 반영할 때 해당 섹션을 교체하고, 프로젝트 실행 방법이나 Works·About·Blog 등 다른 페이지의 기획은 보존한다.

2. 최종 경험
여자 실루엣이 걷다가 멈춰 작품을 바라보는 인트로 이후 작품 탐색이 시작된다. 사용자가 아래로 스크롤하면 작품들이 오른쪽에서 왼쪽으로 이어서 이동한다. 스크롤 한 번에 작품 하나씩 이동하는 제한 없이, 입력량에 따라 여러 작품을 연속해서 지나갈 수 있다. 호버한 작품만 컬러로 전환되며 해당 작품의 제목과 제작년도가 하단에 80px bold 한 줄로 글자별 등장한다.

5. 작품 나열과 스크롤
Z축 포함안 채택 확정
- Z축 기울기 동작을 기본 적용하고 상단 비교 토글을 제거한다.
- 작품 열 전체를 화면 중앙 기준으로 기울인다. 마우스가 오른쪽이면 오른쪽은 사용자에게 가까워지고 왼쪽은 멀어지며, 왼쪽이면 반대가 된다. 위아래 이동은 기존처럼 마우스 반대 방향으로만 이동하고 기울기에 영향을 주지 않는다.
- 임시값: perspective 1200px, Y축 회전 최대 ±10도. 카드별 Z 이동은 제거하고 화면 너비의 공통 평면을 회전시킨다. 스크롤 위치와 무관하게 회전 중심은 화면 중앙을 유지한다.
- 컬러 정책은 이미 확정한 기본 전체 컬러 방식을 유지한다. 모션 감소 및 터치에서는 마우스 깊이 이동을 적용하지 않는다.
확정 동작
- 작품들을 가로 흐름으로 배치하여 스크롤에 따라 연속적으로 탐색한다.
- 아래로 스크롤: 작품 전체가 오른쪽에서 왼쪽으로 이동하며 다음 작품이 오른쪽에서 들어온다.
- 위로 스크롤: 반대 방향으로 이동하며 이전 작품을 다시 볼 수 있다.
- 스크롤 입력의 양에 비례해 이동 거리를 갱신한다. 작은 입력에는 조금, 큰 입력이나 지속 입력에는 더 많이 이동한다.
- 마우스 휠과 트랙패드 모두에서 연속 입력이 반영되어야 한다.
- 입력이 끝나면 현재 이동 위치에서 멈춘다. 부드러운 잔여 이동을 적용하더라도 작품 중앙에 강제로 정렬하지 않는다.
- 진행 중 새 입력이나 반대 방향 입력을 무시하지 않는다.
- 작품은 원본 비율을 유지하며, 늘어뜨리거나 임의로 잘라 표시하지 않는 것을 기본으로 한다.
- 작품 표시 크기는 이전의 80%, 작품 슬롯 사이 간격은 이전보다 20% 확대한다. 데스크톱·모바일에 모두 적용한다.
구현 원칙
- 작품 인덱스를 한 칸씩 증가시키는 전환 큐 대신, 연속적인 이동 위치를 기준으로 화면을 갱신한다.
- 스크롤 위치 또는 입력량을 가로 이동량에 매핑한다. 페이지 스크롤과 별도 휠 처리로 같은 입력이 중복 반영되지 않도록 한다.
- 작품 교체 완료를 기다리는 타이머, 작품별 입력 잠금, scroll-snap 등의 이전 로직을 제거하거나 교체한다.
- 스크롤 감도와 부드러움은 별도 조정값으로 관리한다. 과도한 관성으로 사용자가 원하는 작품을 지나치지 않도록 한다.
- 레퍼런스의 배치 리듬은 실제 화면을 비교해 맞춘다. 행 수, 세로 오프셋, 이미지 크기·간격은 이번 요구만으로 임의 확정하지 않는다.
- ‘연속 스크롤’은 ‘끝없이 반복되는 무한 갤러리’를 뜻하지 않는다. 마지막 작품 이후 첫 작품으로 순환하는지는 별도 결정한다.
6. 호버 작품 정보 표시 (2026-09-29 최신 변경)
확정 동작
- 테스트 페이지 전체의 폰트는 Pretendard로 적용한다. 제목·년도는 기존 80px 및 굵기 800을 유지한다.
- 중앙 작품 판정으로 정보를 표시하는 기획은 취소한다. 실제 이미지에 호버한 작품의 제목과 제작년도를 표시한다.
- 제목과 년도를 `제목 / 년도` 형식(슬래시 양쪽 공백)으로 묶어 80px, bold, 한 줄로 표시한다. 구분자와 년도도 제목에 이어 같은 글자별 등장 애니메이션을 적용한다.
- 호버 해제 시 마지막 글자부터 역순으로 아래로 내려가며 사라진다.
- 등장과 퇴장 모두 위치 이동과 투명도 변화를 함께 적용한다. 등장 도중 호버를 해제하면 그 순간의 위치·투명도·전체 진행 시점에서 역재생하며, 아직 등장하지 않은 글자가 갑자기 표시되지 않는다.
- 퇴장 재생 중 다른 작품에 호버하면 이전 퇴장을 즉시 취소하고 새 작품의 등장 애니메이션을 시작한다. 같은 작품에 다시 호버해도 등장을 재시작한다.
- 이전 애니메이션 프레임이 새 제목을 숨기지 않도록 취소한다. 모션 감소 설정에서는 즉시 표시·제거한다.
- Index의 이 정보 영역에는 설명·제작도구·크기 등을 추가하지 않는다. 상세 정보는 기존 상세 관람 흐름에서 다룬다.
구현 초깃값 제안 — 최종 수치 아님
- 굵기 800, 글자 등장·퇴장 480ms, 글자 간 지연 최대 35ms, 전체 지연 최대 700ms.
- 등장·퇴장 재생 속도는 모두 위 타임라인의 1.5배로 확정한다(글자당 실제 320ms, 지연도 1/1.5). 중간 역재생도 동일 속도를 적용한다.
- y, g 등 하단으로 내려오는 글자를 위해 글자 마스크에 하단 0.2em 여유를 둔다(임시 구현값).
- 데스크톱의 긴 제목 넘침 처리는 후속 결정이다. 모바일 정보는 7-1절의 세로 배치를 적용한다.
7. 이미지 컬러와 호버
- 1안으로 확정하고 상단 비교 토글은 제거한다. 호버가 없으면 전체 컬러. 호버하면 해당 작품은 컬러를 유지하며 약간 확대되고 나머지는 연한 흑백. 해제하면 전체 컬러로 복귀한다.
- 비호버 작품의 흑백 임시 구현값은 grayscale(1), opacity 0.55로 밝은 배경과 혼합한다.
- 호버한 이미지는 grayscale(0), opacity 1로 전환한다. filter와 opacity에 350ms ease transition을 적용한다. 빠른 호버 교체 시 이전 이미지의 잔여 컬러는 이 시간 동안 사라진다.
- 호버 시 약한 확대는 유지하고, 해제 시 원래 크기로 되돌린다.
- 확대 시 주변 작품의 간격이나 위치가 밀리지 않도록 한다.
- 호버 확대량은 원래 3%에서 50% 늘린 4.5%(scale 1.045)로 조정한다. 전환 시간은 200ms다.
- 전체 페이지 마우스 이동에 따른 작품 열의 이동량은 기존 대비 50% 증가한다. X 최대 기준값 16→24px, Y 24→36px이며 기존 작품별 깊이 계수는 유지한다.
- 호버는 연속 스크롤과 전체 페이지 마우스 반응을 멈추지 않는다.
- 모바일은 아래 전용 동작을 적용한다.
7-1. 모바일 전용 동작 (확정)
- 기본적으로 모든 작품은 흑백이며, 화면 중앙에 오는 작품 하나만 컬러로 표시한다.
- 중앙 작품의 제목과 년도를 하단에 세로로 표시한다. 제목이 위, 년도가 아래이며 슬래시 구분자는 사용하지 않는다.
- 작품은 좌우 터치 스와이프로 탐색한다. 손가락을 왼쪽으로 움직이면 다음 작품, 오른쪽으로 움직이면 이전 작품으로 이동한다.
- 마우스 기반 X/Y 이동과 Z축 기울기, 호버 확대 및 호버 작품 선택은 적용하지 않는다. 스와이프에 필요한 가로 이동만 허용한다.
- 인트로 중에는 모든 작품을 흑백으로 유지하고 탐색 활성화 이후 중앙 작품을 선택한다.
모바일 구현 기본값 — 조정 가능
- 화면 너비 768px 이하 또는 hover:none 및 pointer:coarse 환경을 모바일로 분류한다. 회전·화면 크기·입력 환경 변경 시 갱신한다.
- 중앙 좌우 화면 너비 25% 안의 가장 가까운 작품 하나를 선택하며 10px의 경계 여유를 둔다(기존 15%에서 확대). 중앙에 작품이 없으면 모두 흑백이고 정보를 숨긴다.
- 모바일 작품 사이 간격은 10.8vw에서 32.4vw로 3배 확대한다. 데스크톱 간격은 유지한다.
- 제목·년도 묶음의 세로 중심을 실제 선택된 이미지 하단과 화면 하단 안전 영역 사이의 중간에 배치한다. 이미지 로딩·화면 회전 시 다시 측정한다.
- 제목 크기는 clamp(24px, 6vw, 40px), 년도는 20px이며 Pretendard를 사용한다. 제목은 길면 줄바꿈한다.
- 제목·년도는 세로 배치를 유지하며 중앙 작품에 맞춰 글자별 상승·페이드 등장, 역방향 퇴장 애니메이션을 재생한다. 등장 중 중앙을 벗어나면 현재 진행 지점부터 되감고, 새 중앙 작품이 생기면 이전 재생을 취소하고 새 정보를 등장시킨다. 기본 속도는 데스크톱과 동일한 1.5배이며 모션 감소 설정에서는 즉시 표시·제거한다.
- 기존 연속 이동 원칙에 따라 스냅은 추가하지 않고 손가락 이동량을 1:1로 반영한다.
- 손가락을 놓으면 최근 스와이프 속도에 비례한 관성 이동을 적용한다. 빠르게 넘기면 여러 작품을 지나가며 서서히 감속한다. 관성 중에도 중앙 작품 정보·컬러를 갱신한다.
- 다시 터치하면 즉시 멈추고 손가락을 따라온다. 터치 취소, 다중 터치, 창 포커스 해제 시 중단한다. 잠시 멈췄다가 손을 놓거나 모션 감소 설정에서는 관성 없이 멈춘다.
- 관성 임시 조정값: 최대 속도 4px/ms, 감쇠 시간상수 420ms, 최근 입력 유효시간 100ms. 목록 양 끝에서는 멈추며 스냅/무한 반복은 추가하지 않는다.
8. 구현 확인 목록
- [ ] 모바일에서 중앙 작품만 컬러이며 제목·년도가 위아래 순서로 표시된다.
- [ ] 모바일 좌우 스와이프 및 취소가 정상 동작하고 마우스 기반 이동·기울기가 없다.
- [ ] 첫 진입 시 실루엣이 걷다가 멈춰 바라본 후 탐색이 활성화된다.

- [ ] 작은 입력과 큰 입력의 이동 거리가 다르다.
- [ ] 연속 입력으로 여러 작품을 중간 정지 없이 지나갈 수 있다.
- [ ] 입력 종료 후 작품이 중앙으로 자동 스냅되지 않는다.
- [ ] 전환 중 추가 입력이나 방향 반전이 막히지 않는다.

- [ ] 기본 전체 컬러이며 호버 시 나머지 작품만 연한 흑백으로 전환되고 해제하면 전체 컬러로 복귀한다.
- [ ] 확대 때문에 주변 배치가 밀리지 않는다.
- [ ] 화면 크기 변경 후에도 전체 페이지에서 마우스 반응이 동작한다.
9. Codex 작업 범위
기존 Index 구현을 확인한 후 위 기획을 반영한다. 특히 작품 단위 스냅·입력 잠금·방향 매핑·정보 표시·흑백 호버 관련 기존 로직의 충돌을 정리한다. 이 문서와 충돌하는 이전 Index 기획은 적용하지 않는다.
Works 등 다른 페이지의 기존 기능은 이번 개정 범위에 포함하지 않는다. 기존 README 전체를 지우지 말고 Index 기획 섹션만 교체한다. 미확정 항목은 확정 요구와 구분하여 기록하고, 구현 과정의 임시 선택을 최종 결정으로 표기하지 않는다.

일반 Markdown은 파일을 넣는 것만으로 전체가 자동 전달된다고 가정하지 않는다. AGENTS.md는 Codex가 읽는 프로젝트 지침으로 사용하고, 상세 문서는 명시적으로 읽게 한다. 지침 추가 후 새 작업 대화에서 시작하고 첫 메시지에도 경로를 써준다.

### 첫 요청문 — 아래를 Codex에 전달

> docs/CODEX_HANDOFF.md를 먼저 끝까지 읽고 docs/reference/의 최신 PDF와 와이어프레임을 확인해줘. 기존 프로젝트 구조와 사용 가능한 작품·실루엣 자산도 확인해줘. 읽은 파일, 이번 구현 범위, 임시 기본값, 누락 자료를 짧게 정리한 뒤 문서의 1차 Index 프로토타입을 구현해줘. 기존 화면을 보존하며 별도 테스트 경로 또는 컴포넌트에서 작품 3개를 고정 순서로 시작해줘. 첫 자동 등장, 단일·연속 입력, 중앙 정착과 돌아보기, 정보 표시, 실루엣 유지/사라짐 비교를 먼저 연결하고 안정화 후 셔플을 추가해줘. 미확정 사항은 문서의 임시 기준을 적용하고 기록해줘. 끝나면 실행 방법, 확인 결과와 남은 문제를 알려줘.

2026-10-01 상세 페이지 이전/다음 작품 탐색

- 이전 클릭: 기존 작품이 오른쪽으로 이동하며 페이드아웃, 이전 작품은 왼쪽에서 들어오며 페이드인. 다음 클릭은 반대 방향이다. 제목·정보는 위치 이동 없이 페이드 교체한다. 전환 시간은 760ms이며 모션 감소 설정에서는 즉시 바뀐다.

2026-10-01 상세 작품 진행 게이지 및 잔여 작품 툴팁
