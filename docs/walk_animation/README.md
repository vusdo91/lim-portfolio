# visitor_intro.webm

> 2026-09-30: 실루엣 인트로는 폐기되었으며 이 폴더는 제작 원본 보관용입니다. `legacy-assets/`에는 public에서 이동한 이전 배포 자산이 있습니다. 현재 페이지는 이 영상을 사용하지 않습니다.

## 파일 사양

- WebM / VP9 + Alpha, 완전 투명 배경, 검은 실루엣
- 1920 × 2560 px / 24 fps / 무음 / CRF 18
- 전체 103프레임, 약 4.292초
- 기존 투명 PNG 프레임(480 × 640)을 Lanczos 방식으로 4배 확대했습니다. 출력 크기는 커졌지만 원본에 없는 세부 묘사가 추가된 것은 아닙니다.
- 인물의 공통 위치·크기·바닥 기준을 유지합니다. 걷기에 따른 자연스러운 상하 움직임은 남아 있습니다.

## 구성

walk 4회 → stop_and_turn 1회 → 마지막 자세 약 0.79초 유지

기존 walk.webm 한 주기 14프레임(약 0.583초)을 네 번 넣어, 직전 통합본의 걷기 반복 구간 28프레임(약 1.167초)을 56프레임(약 2.333초)으로 두 배 늘렸습니다. 재생 속도를 낮춘 것이 아닙니다. 이후 멈춤·돌아보기 동작은 기존 속도입니다.
요청한 인트로 흐름에 따라 turn_and_walk(재걷기)는 포함하지 않았습니다.

## Codex 적용 지침

파일을 요청한 위치 `docs/walk_animation/visitor_intro.webm`에 두고 확인하세요. 실제 브라우저에서 사용할 때는 해당 프로젝트의 정적 자산 경로(public 등) 또는 기존 import 규칙에 맞게 연결해야 합니다. docs 폴더가 자동으로 URL에 노출된다고 가정하지 마세요.

- 하나의 video에서 처음부터 끝까지 재생합니다. 전체 loop는 끕니다.
- muted, playsInline을 사용하고 재생 준비 후 시작합니다.
- 종료 후 마지막 프레임을 유지합니다. src 제거, 언마운트, currentTime=0 초기화를 하지 않습니다.
- 작품·텍스트 노출을 최종 자세에 맞출 경우 3.500초를 기준으로 동기화합니다. ended는 마지막 자세를 유지한 뒤 약 4.292초에 발생한다는 점을 구분하세요.
- 실제 브라우저에서 투명도와 재생 성능을 확인하세요. 일반 동영상 플레이어에서는 투명 영역이 검게 표시될 수 있습니다.
- 이번 파일은 한 번 재생하는 인트로입니다. 연속 스크롤에 따라 무한 걷기·재걷기가 필요한 동작은 별도 설계가 필요합니다.
